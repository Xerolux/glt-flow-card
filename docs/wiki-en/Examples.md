# Examples

The repository ships, among others, under `examples/`:

- `idm-alm6-15.yaml` – iDM-oriented base example.
- `idm-neo2030.yaml` – iDM example in the Neo 2030 design.
- further GLT/AHU examples can be imported directly and refined in the designer.
