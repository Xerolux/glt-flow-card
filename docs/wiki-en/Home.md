# GLT Flow Card Wiki

**GLT Flow Card** is an engineering and visualisation tool for Home Assistant: freely configurable plant diagrams, drag & drop, live data, replay, trends, alarms, maintenance, reports and project management.

## GLT / SCADA showcase

The screenshots are generated automatically from the current build. They show the GLT down to component level — pumps, valves, mixers, hydraulic separators, immersion heaters, tanks, heat exchangers, sensors, media paths, messages and trends — without any custom plant photos.

## Core areas

- **Neo 2030 / Operations Light / Clean / P&ID Dark / Classic SCADA / Standard 2D** as selectable design systems.
- **Home Assistant designer** with native entity pickers and more than 50 GLT components.
- **YAML round-trip**: import → keep editing → export.
- **Project library**, autosave, versions, templates and groups.
- **Auto-routing** between plant objects.
- **Replay and advanced trends** with multiple Y axes, statistics, energy integration and CSV.
- **Alarms, operations, maintenance, user permissions and audit log**.
- **Multi-site** for multiple locations and sub-plants.
- Optional **Companion backend** for cross-device project and audit storage inside Home Assistant.
