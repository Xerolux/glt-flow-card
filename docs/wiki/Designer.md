# Drag-&-Drop Designer

Der integrierte HA-Designer arbeitet direkt mit der aktuellen Home-Assistant-Entity-Liste.

## Arbeitsweise

Baustein aus der Palette ziehen, positionieren, Entity über den nativen Picker zuweisen, Werte/Status konfigurieren und Leitungen verbinden. Gruppen können mit Strg/Shift markiert und gemeinsam verschoben werden.

## Tastatur

- `Ctrl/Cmd + Z`: Rückgängig
- `Ctrl/Cmd + Shift + Z`: Wiederholen
- `Ctrl/Cmd + S`: Projektbibliothek / Speichern
- `Ctrl/Cmd + O`: YAML Import
- `Delete`: Auswahl löschen

## Entitäten

Haupt-Entity, Status, Messwerte, Flussaktivität und KPIs verwenden Home Assistants Entity-Picker. Im externen Pages-Editor werden Entity-IDs manuell vorbereitet und später im HA-Designer zugeordnet.
