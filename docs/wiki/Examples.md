# Beispiele

Im Repository unter `examples/` liegen u. a.:

- `idm-alm6-15.yaml` – iDM-orientiertes Grundbeispiel.
- `idm-neo2030.yaml` – iDM Beispiel im Neo-2030-Design.
- weitere GLT/RLT-Beispiele können direkt importiert und im Designer weiterbearbeitet werden.

Die Online-Dokumentation stellt die Beispiel-YAML ebenfalls bereit.
