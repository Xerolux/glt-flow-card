# 10-08 — The assertions, in the exact artifact

Closes T10-07 and T10-08. Grep group `phase-10-a11y`.

Against the shipped bundle, not the source — the same rule every UI phase has
followed, for the reason Phase 7 learned the hard way when an artifact grep
passed while the surface rendered a confident zero.

## What it asserts

- **Name and role.** Every focusable element has both. A name that resolves only
  from a `title` fails, because a `title` is not a name.
- **Focus visible with colour removed.** The monochrome stylesheet the Phase-7
  and Phase-9 suites already use: a focus ring that is only a colour change is
  invisible in forced colours, and this is exactly the environment a control-room
  kiosk runs in.
- **Focus not obscured.** The focused element's box is within the viewport and
  not covered by a sticky header or overlay.
- **No trap.** Tab from every focusable element eventually returns to the start.
  Dialogs are entered and left by keyboard.
- **Order matches reading order.** Compared against document order for the
  linear surfaces.
- **Announcements.** A control outcome arriving updates a live region once, not
  per re-render. `effect_unknown` announces its sentence, assertively.
- **Reflow.** 320 px and 200 % zoom produce no horizontal page scrolling; wide
  content scrolls inside its own container.

## Vacuity guards

A surface stripped of its role must fail. A name provided only by `title` must
fail. The test must fail if it mounts nothing — assert the count of elements
examined against a floor, because a sweep over zero elements passes every rule.

## Acceptance

Mutation-verified in both directions for role, name and focus visibility, each
recorded with what was mutated and what the failure said.
