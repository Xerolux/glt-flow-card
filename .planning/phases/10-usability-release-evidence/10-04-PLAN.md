# 10-04 — The hundred strings

Closes T10-03. This is the phase's largest single piece of work and the one that
makes I18N-01 true rather than aspirational.

`src/generated-bases/glt-flow-card.base.js` is 5,561 lines with roughly one
hundred distinct hardcoded German UI strings and zero catalog lookups. Every
locale is currently a code edit in this file.

**The sweep fails with the list, not a count.** A count lets the number creep up
unnoticed; a list is the work queue and shrinks visibly.

**Move strings, do not translate them.** The German wording is the shipped
wording and operators know it. Each string moves to `catalog-de.mjs` verbatim
and gains an English sibling. A wording change disguised as a refactor is a
change nobody reviewed.

## Steps

1. `tools/verify-i18n-coverage.mjs`: parse the shipped bundle, find text nodes
   and user-facing attributes not sourced from the catalog, fail with the list.
2. Move the strings in batches, rebuilding and re-running the sweep after each,
   so the list shrinks monotonically and a mistake is attributable to a batch.
3. An allowlist for genuine non-UI literals (CSS values, entity domains, format
   patterns), each entry carrying **why** it is not UI text.

## Acceptance

The sweep reports zero. Adding one hardcoded string fails with that string in
the output. The allowlist has a reason per entry, and a reason of "not UI" is
not a reason.
