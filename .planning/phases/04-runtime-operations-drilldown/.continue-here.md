## Traps This Phase Hit — Read Before Writing Tests

- **The lane workspace is `custom_components/` + `tests/` + the staged card.**
  No `src/`, no top-level `test/`, no `tools/`, and **no `node` binary**. Two
  tests broke on this in two commits. `test_lane_portability.py` now fails any
  component test that reaches outside. Verify with the directories hidden:
  `mv src test tools dist docs schemas` aside, then run pytest.
- **The RED classifier scans a failing test's echoed source.** Writing the
  literal word `ImportError` inside a sentinel body makes pytest print it in the
  traceback and the run is rejected as a broken harness. Put guarded lookups in
  a helper module.
- **A new route needs an optional request field with a default**, or the generic
  policy prober gets a schema rejection instead of a decision and the matrix
  reports the route as denying principals who are in fact allowed.
- **Touching `package.json` invalidates the build manifest**, which cascades
  into ~16 unit failures until you commit, rebuild and re-stage.
- **`build/release/` is gitignored and goes stale on its own.** Run
  `npm run stage:hacs` when release-build tests complain.
- Playwright: `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/opt/pw-browsers/chromium-1194/chrome-linux/chrome`.
