# 04-05 — The panel is composed on the server

> **Reconstructed at close-out**, from this plan, `04-SUMMARY.md` and the code
> at head — not written at execution time. It records what shipped and what the
> plan asked for; it is not a contemporaneous account of the work.

**Status:** complete.

`custom_components/glt_flow_card/panels.py` composes the panel model behind the
Phase-2 policy boundary. Every profiled object opens the same ordered regions,
so an operator does not learn a new layout per equipment type.

The control list arrives **filtered against this principal's current
capabilities**: a forbidden control is absent, not disabled. A disabled control
still announces that the control exists, which is the same enumeration leak in
softer clothing.

The response carries **no domain, service or target at all**. There is nothing
in it for a browser to replay, so the browser cannot become a dispatch path
even by accident.

The trend region renders a declared `history_unavailable` state. HIST-01 assigns
history to Phase 7; inventing content here would have duplicated an ownership
the roadmap had already placed elsewhere.
