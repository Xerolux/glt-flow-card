## Phase Goal

**As an** installation owner, **I want** an extension to add symbols without adding code, **so that** installing one is not a decision about trust.

<objective>Define the contribution format, and make execution structurally impossible.</objective>

<tasks>
<task type="auto">
  <name>Task 1: The manifest and its validator</name>
  <files>src/v100/sdk-manifest.mjs, custom_components/glt_flow_card/sdk_manifest.py</files>
  <action>Define the manifest: namespace, version, supported project schema versions, and contributions of kind symbol, profile, template, descriptor or translation. Validate in both runtimes against a closed schema. For contributed markup, allowlist elements and attributes; reject script, event-handler attributes, external references and foreignObject. Bound manifest bytes, nesting depth and contribution count before interpreting anything.</action>
  <acceptance_criteria>
    - A pack shipping script, an onload attribute, a remote href or a foreignObject is refused, each with its own reason.
    - An element outside the allowlist is refused even if it is harmless, because an allowlist is the point.
    - Bounds are enforced before parse, not after.
    - Both runtimes reach identical verdicts over a shared corpus.
  </acceptance_criteria>
  <verify><automated>node --test test/sdk-manifest.test.mjs && py -3.13 -m pytest tests/components/glt_flow_card/test_sdk_manifest.py -q -x</automated></verify>
  <done>The format cannot express executable content.</done>
</task>
