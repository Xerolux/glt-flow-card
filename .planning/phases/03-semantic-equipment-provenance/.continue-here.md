**New in Phase 3, and worth remembering.** Adding a file the Companion imports
at module scope means adding it to *three* packaging lists —
`tools/stage-hacs-packages.mjs`, `tools/validate-hacs-staging.mjs` and
`test/hacs-staging.test.mjs`. Missing one is invisible locally and red in
`ha-artifacts`. The drift guard now walks the schema directory as well as
`*.py`, so a missing schema fails locally; a new *kind* of asset would not.
