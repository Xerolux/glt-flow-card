## Environment

- **Python.** `tools/python-launcher.mjs` resolves the pinned 3.13 interpreter:
  `GLT_PYTHON`, then the Windows `py -3.13` launcher, then a repository `.venv`
  or `python3.13`. It refuses anything that is not exactly 3.13. Plan commands
  written as `py -3.13 …` are satisfied by the resolved equivalent.
- **Playwright.** Set `PLAYWRIGHT_CHROMIUM_EXECUTABLE` when the container ships
  a Chromium revision that does not match the pinned Playwright version.
- **Build.** `package.json` is hashed into the canonical build manifest, so run
  `npm run build` after changing it or the HACS staging gates will report drift.
