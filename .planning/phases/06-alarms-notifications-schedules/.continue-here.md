## Running the sentinels

```
export PLAYWRIGHT_CHROMIUM_EXECUTABLE=/opt/pw-browsers/chromium-1194/chrome-linux/chrome
node tools/phase6-red-gate.mjs
```

The Python sentinels carry an `expected_red` marker and are deselected from the
default suite; the red gate selects them with `-m expected_red`. Remove the
marker from a file when its owning plan lands. The two Node sentinels are listed
in `PHASE_GATE_SUITES` in `tools/run-unit-tests.mjs`, each annotated with the
plan that releases it.

## Known environment limits

- `npm run test:phase6:release` needs a Docker engine this container does not
  have, so T6-21 is expected to stay `planned` — exactly as T5-16, T4-14, T3-14
  and T2-16 did.
- `api.github.com` returns 403 through the egress proxy, which is the
  source-repository half of `verify:provenance --online`.
- **Playwright.** This container has Chromium **1194** while the pinned
  Playwright **1.62.1** looks for **1234**, so every exact-dist run needs
  `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/opt/pw-browsers/chromium-1194/chrome-linux/chrome`.
  `playwright.config.mjs` already supports the variable. The mismatch is
  pre-existing — `--grep=phase-5-catalog` fails the same way without it and
  passes with it — so do not read the failure as a Phase-6 defect.
